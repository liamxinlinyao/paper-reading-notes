# 证据核查标准

## 统一证据记录

每条核心结论都用以下结构记录：

| 字段 | 要求 |
|---|---|
| 作者声称什么 | 尽量保留原文强度和范围 |
| 证据是什么 | 图、表、附录、引文、访谈材料、数据或分析位置 |
| 证据实际支持什么 | 不超过设计和数据能支持的范围 |
| 适用条件 | 人群、场景、时间、测量、模型或理论边界 |
| 反向/缺失证据 | 相反结果、未报告分析、样本缺口或未验证机制 |
| 我信到什么程度 | speculative / observed / supported / strong |
| 禁止的更强表述 | 明确不能写成因果、普遍规律或机制证明的地方 |

证据等级针对具体主张及其边界，不是论文或期刊的质量分：

- `speculative`：待验证机制、连接、作者推测，或材料不足以核验的主张。
- `observed`：在给定样本和设计中有可定位的结果或材料；识别、测量或迁移仍有限制。
- `supported`：在限定条件下，适合该研究类型的证据支持该主张，关键替代解释经过检查；不自动表示因果或普遍性。
- `strong`：多研究、独立复现或相互补充的证据链显示稳定性，替代解释较少且边界明确；单篇显著结果或名刊发表不足以达到此等级。

摘要、网页占位符或二手转述只能产生待读项，不能支撑持久化结论。预印本可作为证据来源，但注明版本、尚未同行评审的状态与具体局限，不用发表状态替代设计评价。找不到相反证据时写“未检索/未见”，不能写“不存在相反证据”。

## 实验研究

至少检查操纵或处理、随机化、对照条件、依从性/失访、样本量、测量可靠性、效应量及区间、不良或空结果、统计比较范围和替代解释。显著性不等于实际重要性，单次实验不自动证明机制或长期效果。

## 观察与计量研究

至少检查样本与场景、变量如何测量、时间顺序、识别策略、混淆与选择偏差、模型设定、稳健性、效应量、不确定性和外部效度。除非设计有可信识别，否则使用“相关”“与……一致”等表述，禁止把回归系数直接改写成因果效果。

管理学的额外检查：构念与指标是否混同，分析层级是否匹配（个人/团队/组织），共同方法与同源测量问题，多层嵌套、缺失/失访、反向因果和机制测量。按实际设计检查 DiD 的平行趋势/预期效应、IV 的相关性/排除限制、RDD 的阈值操纵与带宽敏感性；固定效应或稳健性检验本身不消除内生性。中介显著不自动识别因果机制。

## 质性研究

至少检查材料来源、抽样逻辑、饱和或案例选择、访谈/观察情境、编码与解释过程、研究者位置、反例、负案例和可转移性。概念丰富不等于普遍代表性，作者解释与材料原话分开记录。

以研究传统为准：不对所有质性研究强制要求编码者一致率或饱和；解释性研究可核查反身性、材料到解释的透明链及情境边界。

## 理论与概念研究

至少检查核心定义和边界、命题之间的逻辑、机制链、与既有理论的差异、适用条件、隐含假设和可证伪含义。概念新颖不等于经验成立；把命题写成待检验主张。

## 方法、综述与元分析

至少检查方法适用问题、关键假设、比较基准、数据/样本覆盖、纳入排除规则、检索范围、异质性、发表偏倚、遗漏风险和可复现性。方法卡记录“以后能解决什么问题”，不只复述作者的方法部分。

## 证据升级门槛

在把内容写入长期知识卡、论文草稿或基金材料前，必须有：可定位来源、足够的来源类型、没有静默升级的 claim strength、支持边界、禁止的更强措辞，以及已记录的矛盾或缺失证据。门槛未通过时，保留为假设、动机、限制、警示或待读项。

问题/连接/研究卡可以长期保存为明确标记的假设，门槛约束的是把它们提升为已成立的知识结论。经验研究保留效应量、单位、区间和统计口径；原文未报告时注明缺失，不推算不存在的数据。理论论文只对定义、命题和推导在给定前提下的成立性评价，不赋予经验验证强度。方法卡的样本量、测量频次和参数区分原文配置与迁移建议；原文未报告功效分析时不发明样本量阈值。
